## Known lab traps (read first)

1. Wait for the blue "resources being provisioned" message to finish (2–5 minutes). Commands fail until the cluster exists.
2. The lab's cordon and drain loops use dollar-sign variables, which get mangled when copied. Here they're single commands with a node-pool label instead.
3. Click "Check Pod Creation" before you delete pod-2. There's a STOP line before that step.
4. The ping steps open an interactive shell inside pod-1. Here each ping runs as one command that finishes by itself, so you never get stuck inside the pod.
5. The checker lags. If a check shows 0 right after a successful step, wait 30–60 seconds and click again.

## Setup (automatic)

```bash
gcloud config get-value project > ~/project
gcloud container clusters list --filter="name=hello-demo-cluster" --format="value(location)" > ~/zone
cat ~/zone | rev | cut -d- -f2- | rev > ~/region
head ~/project ~/zone ~/region
```

All three values must print. If the zone is empty, the lab is still provisioning, so wait a minute and run the block again. Compare ~/region with the REGION in the lab's Task 3 command (`clusters create regional-demo --region=...`). If they differ, run `echo THE-LAB-REGION > ~/region` with the lab's region.

## Migrate to the optimized node pool

Block 1 – create the larger pool:

```bash
gcloud container node-pools create larger-pool --cluster=hello-demo-cluster --machine-type=e2-standard-2 --num-nodes=1 --zone=`cat ~/zone`
kubectl get nodes
```

Check my progress: Create node pool

Block 2 – move the pods off the old pool (cordon, then drain):

```bash
kubectl cordon -l cloud.google.com/gke-nodepool=my-node-pool
kubectl drain -l cloud.google.com/gke-nodepool=my-node-pool --force --ignore-daemonsets --delete-emptydir-data --grace-period=10
kubectl get pods -o=wide
```

The hello-server pods now show a node name containing larger-pool.

Block 3 – delete the old pool (about 2 minutes):

```bash
gcloud container node-pools delete my-node-pool --cluster hello-demo-cluster --zone `cat ~/zone` --quiet
gcloud container node-pools list --cluster hello-demo-cluster --zone `cat ~/zone`
```

Only larger-pool should be listed.

## Task 3 – Regional cluster and chatty pods

Block 1 – create the regional cluster (5–8 minutes):

```bash
gcloud container clusters create regional-demo --region=`cat ~/region` --num-nodes=1
kubectl get nodes
```

You should see 3 nodes, one per zone. kubectl now points at regional-demo automatically.

Block 2 – pod-1 and pod-2, on different nodes:

```bash
cd ~
cat > pod-1.yaml <<'EOF'
apiVersion: v1
kind: Pod
metadata:
  name: pod-1
  labels:
    security: demo
spec:
  containers:
  - name: container-1
    image: wbitt/network-multitool
EOF
cat > pod-2.yaml <<'EOF'
apiVersion: v1
kind: Pod
metadata:
  name: pod-2
spec:
  affinity:
    podAntiAffinity:
      requiredDuringSchedulingIgnoredDuringExecution:
      - labelSelector:
          matchExpressions:
          - key: security
            operator: In
            values:
            - demo
        topologyKey: "kubernetes.io/hostname"
  containers:
  - name: container-2
    image: us-docker.pkg.dev/google-samples/containers/gke/hello-app:1.0
EOF
kubectl apply -f pod-1.yaml
kubectl apply -f pod-2.yaml
kubectl wait --for=condition=Ready pod/pod-1 pod/pod-2 --timeout=120s
kubectl get pod pod-1 pod-2 --output wide
```

Both pods are Running, and the NODE column shows two different nodes.

STOP. Click Check my progress: Check Pod Creation. Don't run the "Move the chatty pod" block until it's green, because that block deletes pod-2.

Block 3 – ping across zones (finishes by itself):

```bash
kubectl exec pod-1 -- ping -c 5 `kubectl get pod pod-2 -o jsonpath='{.status.podIP}'`
```

Note the average time on the last line (rtt min/avg/max).

## Move the chatty pod to the same node

```bash
cd ~
sed -i 's/podAntiAffinity/podAffinity/g' pod-2.yaml
kubectl delete pod pod-2
kubectl create -f pod-2.yaml
kubectl wait --for=condition=Ready pod/pod-2 --timeout=120s
kubectl get pod pod-1 pod-2 --output wide
```

The NODE column now shows the same node for both pods.
